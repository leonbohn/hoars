# Benchmark fixtures

- `ltl/`, `random/`, `hard/`: deterministic parity automata copied from `leonbohn/automata`
  (`benches/fixtures`, see the README there), generated with [Spot](https://spot.lre.epita.fr).
- `spot/`: other shapes (Büchi with state acceptance, generalized Büchi, Rabin, Streett,
  nondeterministic), generated by `scripts/generate_bench_fixtures.sh`.

Benchmarks read every `.hoa` file in these directories, so adding or removing a file changes the
inputs and invalidates earlier numbers. `exclude` in `Cargo.toml` keeps them out of the crate.
